# 3-minute demo script

## 0:00–0:25 — Problem
"During heavy rain, blocked drains can contribute to local waterlogging. Residents may report issues, but prioritising and tracking the response is difficult."

## 0:25–0:55 — Product
"DrainWatch AI brings reporting, location mapping, explainable risk triage and civic status tracking into one workflow."

## 0:55–1:35 — Live report
Submit a sample report. Show the risk score, risk band and each agent's role. Explain that the photo is evidence and the rainfall value is a demo input unless connected to a verified feed.

## 1:35–2:15 — Priority dashboard
Show the map, priority ranking and recommended inspection action. Explain the score weights and why human review is required.

## 2:15–2:40 — Civic response
Change a report from Submitted to Under Review or Inspection Scheduled. Show that residents can see progress.

## 2:40–3:00 — IBM Bob story and impact
Show screenshots of Bob Plan mode, Agent mode implementation, test generation and debugging. Report only measured prototype results, such as number of sample reports processed and median triage time in a controlled test.
